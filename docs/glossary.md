## Заявка и деньги

| Термин | Определение |
| :--- | :--- |
| **Заявка** | Запрос клиента на выплату компенсации по одному заказу |
| **Инцидент** | Проблема с заказом, из-за которой клиент запрашивает компенсацию |
| **Недовоз** | Отсутствие одной или нескольких оплаченных позиций в доставленном заказе |
| **Компенсация** | Деньги или баллы, которые возвращаются клиенту за инцидент |
| **Частичный возврат** | Возврат части суммы платежа, например стоимости одной позиции, а не всего заказа |
| **Промокод** | Код со скидкой на заказ. Скидка распределяется по позициям и учитывается при расчёте суммы возврата |
| **Баллы** | Внутренняя валюта лояльности, которой можно оплатить часть заказа или получить компенсацию |
| **Лимит автоодобрения** | Максимальная сумма возврата по заявке, которую система одобряет без участия оператора |
| **Месячный лимит компенсаций** | Бюджет автоматических выплат на календарный месяц |
| **Пилот** | Запуск автоматической обработки заявок на части пользователей с возможностью быстрого отключения |
| **DELIVERED** | Статус заказа «доставлен», от которого отсчитывается срок на подачу заявки |

## Процесс и роли

| Термин | Определение |
| :--- | :--- |
| **Оператор** | Сотрудник поддержки, который вручную обрабатывает заявки, не решённые системой автоматически |
| **L1** | Первая линия поддержки, которая принимает обращения клиентов в чате и решает типовые случаи |
| **L2** | Вторая линия поддержки, которая разбирает сложные и спорные заявки после передачи с L1 |
| **Автоматическое решение** | Решение по заявке, которое система приняла без участия оператора |
| **Ручная проверка** | Передача заявки оператору в случаях, когда система не может или не вправе решить её самостоятельно |
| **Пограничная ситуация** | Редкий или нестандартный сценарий вне основного процесса, для которого требуется отдельное правило обработки |

## Антифрод

| Термин | Определение |
| :--- | :--- |
| **Антифрод** | Сервис, который оценивает риск мошенничества по профилю клиента и параметрам заявки |
| **Фрод** | Мошенничество со стороны клиента, например жалоба на недовоз, которого не было |
| **Оценка доверия** | Числовой показатель от 0 до 100, который возвращает антифрод. Чем выше значение, тем выше доверие к клиенту |
| **Порог** | Граничное значение показателя, по которому система определяет дальнейший маршрут обработки заявки |
| **Таймаут** | Максимальное время ожидания ответа от внешнего сервиса |

## Платежи и интеграции

| Термин | Определение |
| :--- | :--- |
| **Платёжный шлюз** | Сервис банка или платёжного провайдера, через который проходят платежи и возвраты средств |
| **Идемпотентность** | Свойство операции, при котором повторное выполнение запроса с теми же данными не меняет результат и не создаёт дублей |
| **Ключ идемпотентности** | Уникальный идентификатор запроса, по которому система распознаёт повторные вызовы и возвращает прежний результат без дублирования операции |
| **Вебхук** | HTTP-запрос, который внешняя система отправляет нашему сервису при наступлении события, например для передачи результата возврата |
| **Polling** | Периодический опрос внешней системы нашим сервисом для проверки статуса операции, если вебхук не поступил |
| **Outbox** | Паттерн надёжной отправки событий, при котором событие сначала записывается в таблицу базы данных в одной транзакции с изменением заявки, а затем отправляется в Kafka отдельным процессом |
| **Order Service** | Сервис заказов, отдающий состав заказа, цены позиций с учётом скидок и статус доставки |
| **Пуш-уведомление** | Уведомление клиенту на телефон с результатом рассмотрения заявки |

## Метрики

| Термин | Определение |
| :--- | :--- |
| **TTR** | Время решения проблемы клиента от момента создания заявки до получения денег или отказа. Складывается из Time-to-decision и Time-to-payout |
| **Time-to-decision** | Время от создания заявки до итогового решения об одобрении или отказе с учётом работы оператора при ручной проверке |
| **Time-to-payout** | Время от момента одобрения заявки до подтверждения выплаты банком или начисления баллов |
| **Contact Rate** | Доля доставленных заказов, по которым клиенты обратились в поддержку |
| **Auto-resolution rate** | Доля заявок, закрытых автоматически без участия оператора |
| **Abuse Rate** | Доля денежных средств, выплаченных недобросовестным клиентам, по результатам проверок |
| **Выборочный аудит** | Ручная проверка оператором случайной выборки автоматически одобренных выплат для оценки доли необоснованных компенсаций |
